# dsh-live-meter
DeepSeek Harness余额监控插件（由DeepSeek Harness编写）

## 效果
![效果展示](./Images/show.jpg)

## 功能
- [x] 实时监控余额、Token和输入、输出、缓存 
- [x] 2秒实时更新
- [x] 适配深浅模式
- [x] 跟随主题变化样式
- [ ] 测试所有平台，保证兼容性
- [ ] 自带删除插件按钮

## 安装
|网页版|桌面版|
|-----|------|
| ```dsh plugin --profile web add github:T-PageCode/dsh-live-meter```|使用DeepSeek Harness帮你安装或点击插件->添加插件输入github:T-PageCode/dsh-live-meter。
> [!WARNING]
> 网页版需要关闭dsh web后重新运行dsh web。
> 桌面版需要点击托盘图标退出（或者打开任务管理器结束所有DeepSeek Harness进程）
## DSH安装命令
帮我安装“`https://github.com/T-PageCode/dsh-live-meter`”DSH插件，全程自动安装，遇到兼容性问题就不安装了。

## 兼容性
建议选择0.2.0-rc.2，已验证可正常运行。
